# LiDAR Building Contour Extractor — Setup & Run Guide
## VS Code Setup Instructions

## ✅ Prerequisites — Install These First

### 1. Python (3.9 or higher)
- Download from: https://www.python.org/downloads/
- During install: ✅ CHECK "Add Python to PATH"
- Verify: open terminal → `python --version`

### 2. Node.js (18 or higher)
- Download from: https://nodejs.org/ (choose LTS version)
- Verify: open terminal → `node --version` and `npm --version`

### 3. VS Code Extensions (install from Extensions tab)
- **Python** (by Microsoft)
- **ES7+ React/Redux/React-Native snippets**
- **Prettier - Code formatter**

## 🛠️ Step-by-Step Setup

---

### STEP 1 — Create the Project Folder

Open VS Code. Open Terminal inside VS Code:
`View → Terminal` or press **Ctrl + `** (backtick)

```bash
# Navigate to where you want the project (e.g. Desktop)
cd Desktop

# Create main project folder
mkdir lidar-contour-extractor
cd lidar-contour-extractor

# Create subfolders
mkdir backend
mkdir frontend
```

---

### STEP 2 — Set Up the Backend (Python + Flask)

```bash
# Go into backend folder
cd backend
```

**Copy your `app.py` file into the `backend/` folder.**

Now create the `requirements.txt` file. In VS Code, right-click the `backend/` folder → New File → name it `requirements.txt`, then paste:

```
flask
flask-cors
numpy
scipy
```

Now install the dependencies:

```bash
# Create a virtual environment (keeps packages isolated)
python -m venv venv
```

**Activate the virtual environment:**

- **Windows:**
  ```bash
  venv\Scripts\activate
  ```
- **Mac/Linux:**
  ```bash
  source venv/bin/activate
  ```

You should see `(venv)` appear at the start of your terminal line.

```bash
# Install all required packages
pip install -r requirements.txt
```

Wait for everything to install. You should see "Successfully installed" messages.

---

### STEP 3 — Set Up the Frontend (React)

Open a **NEW terminal tab** in VS Code (click the `+` icon in the terminal panel):

```bash
# Navigate back to project root
cd Desktop/lidar-contour-extractor

# Create React app inside the frontend folder
npx create-react-app frontend

# This takes 2-3 minutes — wait for it to finish
```

After it finishes:

```bash
# Go into frontend folder
cd frontend

# Install lucide-react (for icons used in the component)
npm install lucide-react
```

**Now place your component file:**

Copy `LiDARContourExtractor.jsx` into `frontend/src/` folder.

**Edit `frontend/src/App.js`** — open it in VS Code and replace ALL its content with:

```javascript
import React from 'react';
import LiDARContourExtractor from './LiDARContourExtractor';

function App() {
  return <LiDARContourExtractor />;
}

export default App;
```

---

### STEP 4 — Run the Project

You need **two terminals running at the same time**.

**Terminal 1 — Run the Flask Backend:**

```bash
# Make sure you are in the backend folder
cd Desktop/lidar-contour-extractor/backend

# Activate virtual environment (if not already active)
# Windows:
venv\Scripts\activate
# Mac/Linux:
source venv/bin/activate

# Start Flask server
python app.py
```

You should see:
```
 * Running on http://0.0.0.0:5000
 * Debug mode: on
```

**Leave this terminal running. Do not close it.**

---

**Terminal 2 — Run the React Frontend:**

Click `+` to open a new terminal tab in VS Code.

```bash
# Go to frontend folder
cd Desktop/lidar-contour-extractor/frontend

# Start React app
npm start
```

After ~30 seconds your browser will open automatically at:
```
http://localhost:3000
```

**The app is now running!**

## ❌ Common Errors & Fixes

| Error | Fix |
|-------|-----|
| `python: command not found` | Use `python3` instead of `python`, or reinstall Python with PATH checked |
| `pip: command not found` | Use `pip3` instead of `pip` |
| `venv\Scripts\activate` not working on Windows | Run VS Code as Administrator, or run: `Set-ExecutionPolicy RemoteSigned` in PowerShell |
| `Cannot reach backend` error in browser | Make sure Flask server is running in Terminal 1 |
| `npm: command not found` | Node.js not installed, download from nodejs.org |
| `Module not found: lucide-react` | Run `npm install lucide-react` in the `frontend/` folder |
| Port 5000 already in use | Change `port=5000` to `port=5001` in `app.py` AND change `API_URL` in the `.jsx` file |
| CORS error in browser console | Make sure `flask-cors` is installed: `pip install flask-cors` |

## 🔌 API Endpoints (Backend)

| Method | Endpoint | Purpose |
|--------|----------|---------|
| GET | `/api/health` | Check if server is running |
| POST | `/api/upload` | Upload `.pts` file |
| POST | `/api/process` | Run contour extraction pipeline |
| POST | `/api/export` | Export contour as txt/json/geojson |
| POST | `/api/metrics` | Compute PoLiS and RAE metrics |

Test the backend directly: open browser → `http://localhost:5000/api/health`
Should return: `{"status": "healthy", ...}`
