## 🛠️ Step-by-Step Setup

---

### STEP 1 — Create Project Folder

```bash
cd Desktop
mkdir lidar-contour-extractor
cd lidar-contour-extractor
mkdir backend
mkdir frontend
```

---

### STEP 2 — Set Up the Backend

```bash
cd backend
```

#### 2a — Copy all backend files

Copy your downloaded files so the structure looks exactly like:

```
backend/
├── app.py
├── pipeline.py
├── processors/
│   ├── __init__.py
│   ├── input_data_processor.py
│   ├── band_contour_extractor.py
│   ├── contour_optimizer.py
│   ├── area_calculator.py
│   └── result_handler.py
└── utils/
    ├── __init__.py          ← Do NOT skip this!
    └── clustering.py
```

> ⚠️ Both `processors/__init__.py` and `utils/__init__.py` must exist.
> Without them Python won't recognise these as packages and imports will fail.

#### 2b — Create `requirements.txt`

Right-click `backend/` folder → New File → name it `requirements.txt`:

```
flask
flask-cors
numpy
scipy
```

#### 2c — Create virtual environment

```bash
python -m venv venv
```

#### 2d — Activate virtual environment

- **Windows:**
  ```bash
  venv\Scripts\activate
  ```
- **Mac/Linux:**
  ```bash
  source venv/bin/activate
  ```

You should see `(venv)` at the start of your terminal line.

#### 2e — Install dependencies

```bash
pip install -r requirements.txt
```

---

### STEP 3 — Set Up the Frontend

Open a **NEW terminal tab** (click `+` in the terminal panel):

```bash
cd Desktop/lidar-contour-extractor

# Create React App inside frontend/
npx create-react-app frontend

# Takes 2–3 minutes — wait for it to finish

cd frontend

# Install icon library
npm install lucide-react
```

#### 3a — Delete files you don't need

Inside `frontend/src/`, delete these CRA default files:

```
src/App.css
src/App.test.js
src/index.css
src/logo.svg
src/reportWebVitals.js
src/setupTests.js
```

#### 3b — Replace `src/index.js`

Open `src/index.js` and replace ALL content with:

```javascript
import React from 'react';
import ReactDOM from 'react-dom/client';
import App from './App';

const root = ReactDOM.createRoot(document.getElementById('root'));
root.render(
  <React.StrictMode>
    <App />
  </React.StrictMode>
);
```

#### 3c — Replace `src/App.js`

Open `src/App.js` and replace ALL content with:

```javascript
import LiDARContourExtractor from './LiDARContourExtractor';

export default function App() {
  return <LiDARContourExtractor />;
}
```

#### 3d — Copy all remaining frontend files

Create the new folders and copy your downloaded files:

```
src/
├── LiDARContourExtractor.jsx      ← copy here
├── classes/                       ← create this folder
│   └── VisualizationManager.js    ← copy here
├── hooks/                         ← create this folder
│   └── useApi.js                  ← copy here
└── components/                    ← create this folder
    ├── panels/                    ← create this folder
    │   ├── UploadPanel.jsx        ← copy here
    │   ├── ProcessPanel.jsx       ← copy here
    │   ├── BuildingPanels.jsx     ← copy here
    │   └── ExportPanel.jsx        ← copy here
    ├── VisualizationPanel.jsx     ← copy here
    ├── AlgorithmCard.jsx          ← copy here
    └── ui/                        ← create this folder
        ├── Panel.jsx              ← copy here
        ├── InfoRow.jsx            ← copy here
        └── ErrorToast.jsx        ← copy here
```

> 💡 No `styles/` or `constants/` folders needed —
> styles are defined inside each component and
> `API_URL` lives directly in `hooks/useApi.js`.

---

### STEP 4 — Run the Project

You need **two terminals running at the same time**.

**Terminal 1 — Flask Backend:**

```bash
cd Desktop/lidar-contour-extractor/backend

# Activate venv
venv\Scripts\activate        # Windows
source venv/bin/activate     # Mac/Linux

python app.py
```

You should see:
```
 * Running on http://0.0.0.0:5000
 * Debug mode: on
```

**Leave this terminal running. Do not close it.**

---

**Terminal 2 — React Frontend:**

```bash
cd Desktop/lidar-contour-extractor/frontend
npm start
```

Browser opens automatically at `http://localhost:3000` ✅

## ❌ Common Errors & Fixes

| Error | Fix |
|-------|-----|
| `ModuleNotFoundError: No module named 'processors.clustering'` | Old `processors/__init__.py` — must NOT import clustering. |
| `ModuleNotFoundError: No module named 'utils'` | `utils/__init__.py` is missing — create it. |
| `python: command not found` | Use `python3`, or reinstall Python with PATH checked. |
| `pip: command not found` | Use `pip3` instead. |
| `venv\Scripts\activate` fails on Windows | Run PowerShell as Admin: `Set-ExecutionPolicy RemoteSigned` |
| `Cannot reach backend` in browser | Flask is not running — check Terminal 1. |
| `npm: command not found` | Node.js not installed — download from nodejs.org. |
| `Module not found: lucide-react` | Run `npm install lucide-react` inside `frontend/`. |
| Port 5000 already in use | Change `port=5000` to `port=5001` in `app.py` AND change `API_URL` in `src/hooks/useApi.js`. |
| CORS error in browser console | Run `pip install flask-cors` in the backend venv. |
| Blank page in browser | Check that all files in `src/` were copied correctly. |
| `Cannot find module './LiDARContourExtractor'` | File must be inside `frontend/src/`, not `frontend/`. |

## 🔌 API Endpoints

| Method | Endpoint | Purpose |
|--------|----------|---------|
| GET | `/api/health` | Check server is running |
| POST | `/api/upload` | Upload `.pts` file → InputDataProcessor |
| POST | `/api/process` | Run full pipeline → all CRC classes |
| POST | `/api/export` | Export contour → ResultHandler |
| POST | `/api/metrics` | PoLiS & RAE accuracy metrics |

Test backend directly: `http://localhost:5000/api/health`
Expected: `{"status": "healthy", "version": "2.0.0"}`
